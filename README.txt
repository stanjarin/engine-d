ENGINE D PWA — deploy as an independent GitHub Pages repository.

1. Create a new PUBLIC GitHub repository, for example engine-d.
2. Upload the contents of this folder (not the enclosing folder) to the repository root.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Open https://YOUR_USERNAME.github.io/engine-d/ on your iPhone in Safari.
5. Share > Add to Home Screen. Open it online once to cache all assets; thereafter it works offline.

The four reels and notes are unchanged from the supplied HTML. Notes use browser localStorage.
